About the experiment
The project uses 27,558 NIH/NLM single-cell images with patient-to-cell mappings. Cells from a patient are kept in one data partition to reduce patient overlap between training and evaluation. The test metrics describe this dataset only.
Interpretation
Scores are uncalibrated model outputs; they are not diagnostic probabilities. A real clinical tool would require external, prospective validation and review by qualified professionals. See the API docs and project report for methodology.
